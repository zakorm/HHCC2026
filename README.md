features:
- teacher, student, parent mode
- quick marking and saving to database
- links to extra learning for struggling subjects
- see what your child has been up to

start this project:
   git clone https://github.com/zakorm/HHCC2026
   npm install
   npx expo start --tunnel

built with expo and react native, using nativewind
